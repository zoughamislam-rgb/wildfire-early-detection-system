# Wildfire Early Detection System

**Vision:** Explore autonomous sensor networks that can detect potential wildfire conditions early.

**Objectives:** Develop and test a low-power sensing concept with communications and energy autonomy.

**Team:** Multidisciplinary student team; responsibilities pending assessment.

**Current status:** Preliminary planning and team assessment.
