# Roadmap

## Phase 0 — Problem definition
- Define the deployment environment and target detection lead time.
- Identify wildfire indicators measurable by practical low-power sensors.
- Establish assumptions, constraints, and success metrics.

## Phase 1 — Sensor-node research
- Compare candidate sensing modalities.
- Evaluate sensor limitations, false positives, and environmental robustness.
- Define a first node architecture and acquisition strategy.

## Phase 2 — Energy autonomy
- Build the node power budget.
- Explore solar harvesting, battery sizing, and MPPT options.
- Estimate autonomy under realistic duty cycles.

## Phase 3 — Communications
- Compare viable remote communication technologies.
- Model range, power, latency, network topology, and data volume.

## Phase 4 — Prototype and simulation
- Build a minimal sensor-node prototype.
- Simulate energy, coverage, communications, and detection behavior where appropriate.
- Validate the highest-risk assumptions experimentally.

## Phase 5 — System integration
- Connect multiple nodes to a monitoring layer.
- Add localization, alerts, and decision-support features only after the sensing layer is credible.

## Phase 6 — Field-oriented evaluation
- Test reliability and false-positive behavior in increasingly realistic conditions.
- Document limitations and define the next hardware/system iteration.
